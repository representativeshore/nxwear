# Браслет

Замена приложения Nx Wear для фитнес-браслета B8. Собирает данные с браслета по Bluetooth,
пишет их в Apple Health и считает по ним восстановление.

## Что умеет

- Сбор пульса, HRV, сна, шагов, температуры и заряда с браслета.
- Протокол браслета восстановлен из SDK приложения, разбор кадров отделён от Bluetooth
  и проверяется тестами.
- Стадии сна и гипнограмма, запись сна и замеров в Apple Health без дублей.
- Готовность на день с учётом сна, HRV и нагрузки, тренировки берутся из HealthKit.
- Модели по накопленным данным: ACWR и Banister, HRV-коридор, лаговые корреляции.
- Вся история хранится поштучно, под годовые ряды.
- Виджет на домашний экран, уведомление о пропаже браслета.

## Сборка

Проект генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen), сам `.xcodeproj` не хранится.

```
xcodegen generate
open Braslet.xcodeproj
```

iOS 17 и новее. Для HealthKit и App Group в `project.yml` нужно указать свой `bundleIdPrefix`
и команду подписи.
